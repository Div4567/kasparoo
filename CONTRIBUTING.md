# Contributing to Get Smth

First off, thank you for considering contributing to Get Smth! It's people like you that make it such a great tool for e-commerce support.

## Development Workflow

1. Fork the repo.
2. Create a new branch depending on your feature (`git checkout -b feature/my-new-feature` or `bugfix/issue-description`).
3. Make your local changes.
   - For backend changes, work in the `/backend` directory.
   - For frontend UI changes, work in `/frontend`.
   - For AI RAG, prompting, or LLM updates, work in `/ai_service`.
4. Ensure your code lints and tests pass (if applicable).
5. Push to your fork and submit a Pull Request.

## Environment Setup
Refer to the `README.md` for local setup instructions using Docker, Python, Node, and Ollama.

## Reporting Issues
If you find a bug, please create an Issue outlining:
- The expected behavior
- The actual behavior
- Error logs or stack traces
- Steps to reproduce

Thank you!
